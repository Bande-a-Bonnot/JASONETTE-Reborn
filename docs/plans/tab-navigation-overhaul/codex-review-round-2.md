**Findings**
- **BLOCKER**: Bootstrap preloading breaks reload semantics on the root document. [JasonetteRootView.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/Navigation/JasonetteRootView.swift:60) fetches the entry doc, [JasonetteNavigationView.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/JasonetteNavigationView.swift:90) then instantiates `JasonetteView(document:)`, and [JasonetteViewModel.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/JasonetteViewModel.swift:83) only refetches when `document == nil`. In `.single` mode, and for the bootstrap tab in `.tabs`, `$reload`, pull-to-refresh without `$pull`, and retry paths stop hitting the network and just re-render the stale in-memory document.

- **BLOCKER**: Promotion can select a non-selectable tab and boot into a blank shell. [JasonetteNavigationCoordinator.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/Navigation/JasonetteNavigationCoordinator.swift:39) falls back to `entries.first!` without requiring a document tab, [TabShellState.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/Navigation/TabShellState.swift:14) accepts that selection, and [JasonetteTabShell.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/Navigation/JasonetteTabShell.swift:49) renders `.web/.app/.action` tabs as `Color.clear`. A footer whose first item is non-document, or whose tabs are all non-document, launches with an empty content area.

- **HIGH**: All document tabs are live-loaded immediately, even when hidden. [JasonetteTabShell.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/Navigation/JasonetteTabShell.swift:20) mounts every tab scope up front, [JasonetteView.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/JasonetteView.swift:30) runs `loadIfNeeded()` for every mounted root view, and [JasonetteView.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/JasonetteView.swift:123) only tears down timers on disappear. Hidden tabs therefore fetch, run `$load`, and keep timers alive before the user ever selects them.

- **HIGH**: Footer-tab taps bypass the renderer’s existing URL/view validation. The old path validates schemes in [JasonetteViewModel.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/JasonetteViewModel.swift:150). The new shell builds tab targets from any `URL(string:)` in [JasonetteNavigationCoordinator.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/Navigation/JasonetteNavigationCoordinator.swift:108) and opens/selects them directly in [JasonetteTabShell.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/Navigation/JasonetteTabShell.swift:63). That reintroduces blocked/custom-scheme opens for `web/app` tabs and turns invalid document URLs into selectable error states instead of ignored taps.

- **HIGH**: Tab icon extraction is wrong for normal tabs. [JasonetteNavigationCoordinator.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/Navigation/JasonetteNavigationCoordinator.swift:96) stores `iconURL` from `item.imageURL`, but [JasonDocument.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Core/JasonDocument.swift:88) defines `imageURL` as `url ?? image`. For a standard footer tab with both a target `url` and an `image`, the icon becomes the document URL, so [FooterTabBar.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/Navigation/FooterTabBar.swift:40) tries to render JSON as an image.

- **MEDIUM**: The package still exposes the broken entry point. [JasonetteNavigationView.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/JasonetteNavigationView.swift:35) remains `public`, while the fixed bootstrap/shell path starts at [JasonetteRootView.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/Navigation/JasonetteRootView.swift:11). Any external caller still using `JasonetteNavigationView(url:)` keeps the old broken tab model and silently misses this overhaul.

**Questions**
- The UUIDv7 comment claims later IDs sort after earlier ones, but [UUIDv7.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/Navigation/UUIDv7.swift:3) only guarantees cross-millisecond ordering; within the same millisecond the ordering is random. [TabNavigationCoordinatorTests.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Tests/JasonetteTests/TabNavigationCoordinatorTests.swift:15) sleeps 2ms, so it never exercises the risky case. I would not rely on monotonic ordering from this implementation.

- `transition:"switch"` to a non-selectable tab currently behaves as a miss and falls through to in-stack push via [JasonetteNavigationView.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/JasonetteNavigationView.swift:115) and [TabShellState.swift](/Users/thomas/Projects/Banade-a-Bonnot/JASONETTE-Reborn/JASONETTE-iOS/JasonetteApp/Sources/Jasonette/Rendering/Navigation/TabShellState.swift:36). If that is intentional, fine; if authors expect parity with tapping a `web/app` tab, it is not implemented.

The current tests pass because they mostly pin coordinator state, not end-to-end shell behavior. There is no coverage for bootstrap-tab reload/pull, non-selectable-first-tab boot, eager hidden-tab loading, tab-tap validation, or tab icon parsing.
