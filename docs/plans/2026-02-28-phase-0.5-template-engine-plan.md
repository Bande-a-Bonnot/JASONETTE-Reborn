# Phase 0.5: Template Engine

## Goal

Build a standalone TypeScript template engine that transforms `$jason` documents by evaluating template expressions and structural directives (`{{#each}}`, `{{#if}}`). This is the core runtime that all platforms (web, iOS, Android) will share.

## Deliverables

1. **`packages/template-engine/`** — TypeScript package with Vite (library mode) + Vitest
2. **Template parser** — Handles `{{var}}`, `{{#each}}`, `{{#if}}/{{#elseif}}/{{#else}}`
3. **Expression evaluator** — JSEP + custom AST walker with security layers
4. **Mixin resolver** — `@` mixin operator with recursion limits
5. **Conformance test results** — Expected output for Phase 0 fixtures
6. **npm package** — `@jasonette/template-engine`

### 0.5.2 — Expression Evaluator

TDD: write tests first for each expression type.

- [x]JSEP parsing integration
- [x]AST walker for:
  - Identifier resolution (`$jason`, `$get`, `$params`, `$root`, `$index`, `$env`, `$cache`, `$keys`)
  - Literal values (string, number, boolean, null)
  - MemberExpression (dot and bracket access)
  - BinaryExpression (`+`, `-`, `*`, `/`, `%`, `==`, `!=`, `===`, `!==`, `<`, `>`, `<=`, `>=`, `&&`, `||`)
  - UnaryExpression (`!`, `-`, `+`)
  - ConditionalExpression (ternary `? :`)
  - CallExpression with function allowlist
- [x]Security layers:
  - Property blocklist (`__proto__`, `constructor`, `prototype`) on MemberExpression
  - AST validation: reject assignment, statements, unsupported node types
  - Complexity limits: max depth 20, max 50 nodes
  - Timeout: 10ms per expression evaluation
  - Function allowlist: `Math.*`, `JSON.stringify`, `JSON.parse`, `parseInt`, `parseFloat`, `String`, `Number`, `encodeURIComponent`, `decodeURIComponent`
- [x]Expression cache (LRU, 1000 entries for parsed ASTs)
